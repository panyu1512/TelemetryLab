# Registro de cambios

Aquí se documentan, en español, los cambios destacables de este proyecto. Es la
traducción de [CHANGELOG.md](CHANGELOG.md), que sigue siendo la referencia: las
notas de cada versión en GitHub se publican en los dos idiomas a partir de
estos dos archivos.

El formato se basa en [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/),
y este proyecto sigue el [Versionado Semántico](https://semver.org/lang/es/spec/v2.0.0.html).

Las versiones hasta la 1.29.1 solo están documentadas en inglés, en
[CHANGELOG.md](CHANGELOG.md). El título de la sección de cambios pendientes se
deja en inglés a propósito: es el que busca el script de publicación.
